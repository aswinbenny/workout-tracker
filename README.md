# Workout Tracker

A minimalist offline-first Workout Tracker built as a Progressive Web App (PWA).

![Platform](https://img.shields.io/badge/PWA-Ready-blue)
![Offline](https://img.shields.io/badge/Offline-Yes-success)
![Storage](https://img.shields.io/badge/Storage-LocalStorage-orange)
![License](https://img.shields.io/badge/License-Personal-lightgrey)

---

## Features

- 📱 Installable on Android and iPhone
- 🌐 Progressive Web App (PWA)
- 💾 Offline-first
- 🔒 No login required
- 🗂 LocalStorage persistence
- 🏋 Workout Plan Editor
- 📖 Exercise Library
- 📈 Workout History
- 🌙 Dark Mode

---

## Technology

- HTML5
- React 18 (CDN)
- Tailwind CSS
- JavaScript
- LocalStorage
- Service Worker
- Web App Manifest

## Installation

Clone the repository

```bash

```

Run locally

```bash
python -m http.server
```

or

Use VS Code Live Server.
